# X3MiraPhone

X3MiraPhone is the phone-side half of X3Mira, a screen-mirroring pair for RayNeo X3 Pro AR glasses. It captures the phone's own screen and audio, streams them over Wi-Fi to the glasses, and injects back the taps, scrolls, and text the wearer sends from the glasses' temple pad. Because the glasses have no cellular connection of their own, this app also makes every AI model call on the glasses' behalf when the pair is running over a direct Wi-Fi link, so the API credentials never have to leave the phone.

## Download

Both companion APKs are published in the [X3Mira](https://github.com/tropicalstream/X3Mira) repository: [X3Mira-phone.apk](https://github.com/tropicalstream/X3Mira/blob/main/X3Mira-phone.apk).
